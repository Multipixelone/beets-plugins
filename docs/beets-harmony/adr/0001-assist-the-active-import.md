# Assist the active import

Beets Harmony will extend the active beets candidate prompt rather than require a second command to inspect the same files. When MusicBrainz has no candidates it will begin Spotify discovery automatically; for weak candidates it will offer an explicit prompt choice. It will use the exact current import task and hand a selected Spotify release to hosted Harmony with a plain URL, OSC 52 clipboard copy, and terminal QR code. The user accepts one Harmony **Import into MusicBrainz** tap, completes MusicBrainz's required human review, and explicitly acknowledges submission before polling begins; the plugin then finds the Submitted Release and resumes the same import. Seamless resumption will be isolated behind a compatibility adapter for the pinned beets internals, with the ordinary `enter Id` prompt and OSC 52 copied MBID as a safe fallback. This avoids file movement and repeated directory selection without treating Spotify as the tagging authority.
