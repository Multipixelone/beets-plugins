# Keep Spotify out of import metadata

Beets Harmony will use a narrow official Spotify API client for Discovery Metadata instead of enabling beets' Spotify metadata source. Import Metadata remains MusicBrainz-only so Spotify candidates cannot be automatically selected by the normal importer and MusicBrainz-specific fields remain available. The duplicated OAuth, search, album, and pagination code is accepted to keep this boundary explicit. Spotify and other supported external identifiers are retained when MusicBrainz supplies them through release relationships; they remain appreciated enrichment rather than alternative metadata authorities. The plugin is read-only with respect to files, library items, and task proposal state until it has validated a MusicBrainz proposal, after which normal beets code owns all writes.
