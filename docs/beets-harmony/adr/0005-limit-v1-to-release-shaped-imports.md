# Limit v1 to release-shaped imports

Beets Harmony v1 will assist album-mode imports, including singles and EPs represented as releases, but not beets singleton-track imports. Digital Source Albums may qualify for automatic Spotify selection; a Source Album identified as CD, vinyl, or another physical edition always requires explicit confirmation because Spotify describes a digital edition. The user can correct the medium and other Edition Identity details in the MusicBrainz editor before submission.
